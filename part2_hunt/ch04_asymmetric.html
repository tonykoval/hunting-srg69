Chapter 4 · Part II Cayley & the Asymmetric Wall

The orbit-matrix sweep closes graphs with a small automorphism. Two cases remain: the most symmetric possibility (a Cayley graph), which is settled cleanly, and the least symmetric (a fully rigid graph), which is where the real wall stands.

4.1   Cayley graphs: only one group, and it fails

A Cayley graph $\mathrm{Cay}(G,S)$ on a group $G$ of order $69$ is an $\mathrm{SRG}$ exactly when the connection set $S$ is a partial difference set (PDS) with the right parameters. The arithmetic of $69 = 3\cdot 23$ is decisive: because $\gcd(3,22)=\gcd(23,2)=1$, there is only one group of order $69$ — the cyclic group $\mathbb{Z}_{69}$. So the entire Cayley question is whether $\mathbb{Z}_{69}$ carries a $(69,20,7,5)$-PDS.

Theorem (no Cayley graph)

There is no $\mathrm{SRG}(69,20,7,5)$ that is a Cayley graph. The only group of order $69$ is $\mathbb{Z}_{69}$; an exhaustive / high-effort PDS search over $\mathbb{Z}_{69}$ (simulated annealing, $500\text{k}$ restarts, and a complete cyclic-Cayley SAT closure, UNSAT in $9$ s) finds none — the best near-miss leaves $48$ constraint violations. $\square$

This removes the most-symmetric end of the spectrum. Together with Chapter 3 (no automorphism of odd prime order) it means any graph still in play is either an involution-symmetric graph (the open $p=2$ sweep) or completely rigid.

4.2   The rigid case: Euclidean / Gram filtering

For a rigid graph there is no symmetry to quotient by, so the search is over full $69\times69$ adjacency matrices. The sharpest necessary condition we can propagate is spectral. An $\mathrm{SRG}(69,20,7,5)$ has its $5$-eigenspace of dimension $23$; mapping vertices to that space gives unit vectors whose Gram matrix $G$ is positive semidefinite of rank exactly $23$, with inner products fixed by adjacency. Any partial adjacency whose forced Gram matrix is not PSD of rank $\le 23$ cannot extend — a powerful pruning oracle that needs no symmetry.

We built this as a Gram-PSD / Euclidean backtracker (srg69-extension --vseq --gram, rank cap $23$) and ran it on an algebraic sub-family of $51$ near-miss candidates. The result quantifies the wall:

Gram-PSD backtracker, 4-candidate sample200 s each~4.3 M (≈21 k/s)all TIMEOUT — 0 exhausted, 0 feasible
A two-level cluster wall

The per-candidate search tree vastly exceeds $4.3$ million nodes, so a desktop cannot exhaust even one candidate at $200$ s — the cluster's hour-plus budgets are required. And the $51$ candidates are only the algebraic sub-family; a full non-existence proof needs the complete triangle-neighbourhood enumeration, which is far larger again. Non-existence of $\mathrm{SRG}(69,20,7,5)$ is cluster-scale at every level.

The honest position: the Euclidean filter is sound (it never rejects a real graph) and validated, but on a single machine it neither exhausts the rigid space nor produces a graph. Like the $p=2$ sweep, it is a distributed-compute problem — and that, plus the decision it would settle, is Chapter 5.
